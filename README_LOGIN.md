# Aegean Robotics — Smart Inventory 4.2 (Login)

Αυτή η έκδοση προσθέτει **υποχρεωτικό login** στο υπάρχον Smart Inventory, διατηρώντας τις λειτουργίες «Πού είναι;», Gemini, AI Απογραφή, Ντουλάπες, Δανεισμούς, προειδοποιήσεις και **Export Excel**.

## Γρήγορη εγκατάσταση σε Windows

1. **Κράτησε αντίγραφο της προηγούμενης εγκατάστασης.** Αποσυμπίεσε το νέο ZIP σε νέο φάκελο. ΜΗΝ αντικαταστήσεις τον παλιό φάκελο και μην σβήσεις το παλιό `data/`.
2. Αν έχεις καταχωρίσει πραγματικά δεδομένα στην 4.0/4.0.1, **πριν από κάθε εκκίνηση** της νέας έκδοσης, κλείσε όλους τους server και τρέξε `IMPORT_FROM_4_0_1_WINDOWS.bat`. Διάλεξε τη διαδρομή του ΠΑΛΙΟΥ φακέλου. Το script **δεν αντικαθιστά** ήδη υπάρχουσα νέα βάση.
3. Κάνε διπλό κλικ στο **`RUN_ME_WINDOWS.bat`**. Θα εγκαταστήσει Pillow/qrcode, αν χρειάζεται, και θα σου ζητήσει να δημιουργήσεις τον πρώτο διαχειριστή από το παράθυρο των Windows.
4. Δώσε ένα username και έναν νέο, μοναδικό κωδικό **τουλάχιστον 12 χαρακτήρων**. Ο κωδικός δεν εμφανίζεται όταν τον πληκτρολογείς. Δεν υπάρχει προκαθορισμένο admin/password.
5. Άνοιξε **http://127.0.0.1:8989**. Κάνε login και πήγαινε στο αριστερό μενού **Χρήστες** για να δημιουργήσεις λογαριασμούς.

Το Gemini key μπαίνει στο τοπικό `.env` όπως πριν. **Μην γράφεις στον χώρο login τα στοιχεία του WordPress.** Είναι ανεξάρτητοι λογαριασμοί.

## Ρόλοι

| Ρόλος | Δικαιώματα |
| --- | --- |
| Administrator | Όλες οι λειτουργίες, αλλαγές ρυθμίσεων, δημιουργία/απενεργοποίηση χρηστών, reset password |
| Member | Αναζήτηση, φωτογραφία/Gemini, κινήσεις αποθέματος, δανεισμοί, απογραφές, Excel. Δεν αλλάζει κρίσιμες ρυθμίσεις ούτε χρήστες. |
| Viewer | Αναζήτηση, ανάγνωση αποθεμάτων/θέσεων/δανεισμών και Excel. Δεν καταχωρίζει αλλαγές ή κλήσεις AI. |

Προβλέπονται **Έξοδος**, **Αλλαγή προσωπικού κωδικού**, **Λίστα χρηστών**, αλλαγή ρόλου, απενεργοποίηση και επαναφορά κωδικού από τον διαχειριστή. Αλλαγή ρόλου ή password ακυρώνει τις ήδη ανοιχτές συνεδρίες.

Οι κωδικοί προστατεύονται με **PBKDF2-HMAC-SHA256 και μοναδικό salt**. Η σύνδεση χρησιμοποιεί τυχαία session tokens που αποθηκεύονται ως SHA-256 digest, HttpOnly/SameSite=Strict cookie, CSRF protection σε αλλαγές και χρονικό όριο συνεδρίας 12 ωρών. Υπάρχει κλείδωμα ύστερα από επαναλαμβανόμενες αποτυχημένες συνδέσεις. Το ιστορικό ενεργειών χρήστη αποθηκεύεται στον πίνακα `auth_activity` της βάσης, αλλά **δεν είναι ακόμη πλήρες σύστημα audit/compliance**.

## Σύνδεση με υπάρχουσα ιστοσελίδα WordPress

Η διεύθυνση `https://icsdweb.aegean.gr/aegeanrbtcs/` μπορεί να φιλοξενήσει έναν σύνδεσμο με τίτλο «Εργαστηριακή Αποθήκη», **αφού** η εφαρμογή εγκατασταθεί σε διαδικτυακό server. Η πρόσβαση μόνο στο WordPress Admin **δεν αρκεί** για να ανεβάσεις και να τρέξεις αυτό το Python backend στο πανεπιστημιακό hosting.

**ΠΡΟΣΟΧΗ:** Η έκδοση 4.2 έχει πιλοτικό login για τοπική χρήση και δοκιμές. **Δεν αποτελεί ελεγμένη production εφαρμογή για έκθεση στο δημόσιο Internet.** Δεν αρκεί η ύπαρξη login για να θεωρείται ασφαλής. Πριν από δημόσια δημοσίευση απαιτούνται:

- Κατάλληλος server διαχειριζόμενος από τους υπευθύνους (VPS ή υποδομή Πανεπιστημίου), HTTPS/TLS, reverse proxy, firewall· καμία απευθείας δημοσίευση της θύρας `8989`.
- Περιορισμός network access, backup/restore, ενημερώσεις ασφαλείας, παρακολούθηση αιτημάτων, server hardening και **ανεξάρτητος έλεγχος ασφάλειας**.
- Ρύθμιση `AUTH_SECURE_COOKIE=1` **στο περιβάλλον του server** (όχι μέσα στο `.env`, που προορίζεται για Gemini), όταν η εφαρμογή σερβίρεται μόνο μέσω HTTPS και ο reverse proxy προωθεί σωστά το `Host`.
- Αξιολόγηση προστασίας προσωπικών δεδομένων για ονόματα δανειζόμενων και φωτογραφίες. Μη δημοσιοποιήσεις το Gemini key ή τη βάση δεδομένων.

Αν προτιμήσεις στο μέλλον **ίδιους κωδικούς με WordPress (SSO)**, θα χρειαστεί ξεχωριστή ασφαλής ενσωμάτωση με OAuth/OIDC ή τον πάροχο SSO του Πανεπιστημίου. Η παρούσα έκδοση δεν συνδέεται με το σύστημα χρηστών WordPress.

## Δοκιμές

- `python test_auth.py` — αυτόματη δοκιμή backend login, CSRF, περιορισμού ρόλων, εξαγωγής και logout.
- Οι παλιές δοκιμές 4.0 δεν περιλαμβάνουν login, επομένως χρειάζονται προσαρμογή για τα προστατευμένα endpoints.

Δεν έχει γίνει πραγματική online εγκατάσταση, ούτε δοκιμή με τους WordPress λογαριασμούς ή το προσωπικό σου Gemini API key.
