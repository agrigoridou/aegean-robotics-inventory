# Aegean Robotics — Smart Inventory 4.2 (με Login)

**Πρώτη εκκίνηση:** `RUN_ME_WINDOWS.bat` → Δημιουργία πρώτου Administrator → **http://127.0.0.1:8989**.

**Έχεις ήδη δεδομένα στην έκδοση 4.0/4.0.1;** Μην εκκινήσεις ακόμα τη νέα έκδοση. Κράτησε αντίγραφο της παλιάς και τρέξε πρώτα `IMPORT_FROM_4_0_1_WINDOWS.bat` αφού κλείσεις τους παλιούς server. Δεν αντικαθίστανται υπάρχουσες βάσεις.

Όλες οι οδηγίες για login, ρόλους χρηστών, μεταφορά δεδομένων και τη σύνδεση WordPress βρίσκονται στο [README_LOGIN.md](README_LOGIN.md).

## Λειτουργίες

- **Πού είναι;** — Αναζήτηση θέσης, π.χ. Raspberry Pi 4, και ποσότητας ανά ράφι.
- **Αποθήκη** — Ενημερώσεις ποσότητας, νέα είδη, μετακινήσεις και **Export Excel**.
- **Ντουλάπες** — Ψηφιακές θέσεις, φωτογραφίες ραφιών και Smart Placement.
- **AI Απογραφή** — Gemini για αναγνώριση με υποχρεωτική ανθρώπινη επιβεβαίωση.
- **Δανεισμοί** — Υλικό, υπεύθυνος, project και ημερομηνία επιστροφής.
- **Ειδοποιήσεις** — Ελάχιστα όρια και ενδεικτική πρόβλεψη ζήτησης.
- **AI Βοηθός** — Ερωτήσεις στη φυσική γλώσσα με στοιχεία του inventory.
- **Χρήστες** — Login, ρόλοι admin/member/viewer και αλλαγή κωδικών.

Οι **283 αρχικές εγγραφές** προέρχονται μόνο από το φύλλο SUB.2 Inventory. Η εφαρμογή δεν γνωρίζει αυτόματα την πραγματική θέση χωρίς φυσική επιβεβαίωση.

**Δεν είναι ακόμη online** και **δεν είναι εγκεκριμένη παραγωγική εγκατάσταση δημόσιου Internet**. Για σύνδεση με το WordPress απαιτείται ξεχωριστό ασφαλές Python hosting, HTTPS και έλεγχος ασφάλειας. Απέφυγε να ανοίξεις τη θύρα 8989 από το router.
